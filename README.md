# Exercicios-Introducao-POO- VICTOR RYU NOGUCHI


Repositório com exercícios práticos desenvolvidos em **Java** (com **Maven**) ao longo da disciplina de **Introdução à Programação Orientada a Objetos**, reunindo diferentes atividades e evoluindo dos conceitos básicos até **Design Patterns**.

## Conteúdos Abordados

- **Fundamentos de POO:** Classes, objetos, atributos, métodos, construtores e encapsulamento.
- **Herança e Polimorfismo:** Especialização de comportamentos, reescrita/sobrecarga e tratamento uniforme de tipos (como na modelagem de domínio com `Veiculo`, `CarroPasseio`, `Utilitario` e `Locadora`).
- **Abstração e Interfaces:** Separação entre contrato e implementação para reduzir acoplamento.
- **Design Patterns:** Aplicação de padrões de projeto para resolver problemas recorrentes de estrutura, criação e comportamento com código mais limpo e flexível.
- **Organização de Projeto em Java:** Estruturação em pacotes e gerenciamento de build/dependências com Maven (`pom.xml`).

## Experiência de Aprendizado

Resolver esses exercícios ajudou a enxergar a programação além de apenas "fazer o código funcionar". Na prática, o principal aprendizado foi entender:

- Como dividir responsabilidades entre classes para evitar códigos longos, rígidos ou difíceis de manter;
- Como herança, interfaces e **Design Patterns** facilitam a extensão do sistema sem quebrar o que já existe;
- A importância de testar cenários diferentes e refatorar a modelagem quando surgem novas regras de negócio.
